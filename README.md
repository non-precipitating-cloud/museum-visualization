# 中国博物馆文化资源与公共文化服务的多维可视化分析

**—— 基于馆藏规模、空间分布、文化价值、公共服务与国际比较的可视化研究**

数据可视化项目 · 从官方公开数据到可交互可视化大屏

---

## English Abstract

**Multidimensional Visualization of China's Museum Cultural Resources and Public Cultural Services**

A reproducible, end-to-end data visualization project built entirely on official Chinese public
data: **collection → cleaning → processing → auditing → interactive front end**. It addresses five
questions — resource scale, spatial distribution, cultural-value structure, public cultural
service, and international comparison — and ships as one interactive dashboard plus five focused
analysis pages.

- **Data** — 59 hand-transcribed official sources (National Cultural Heritage Administration,
  Ministry of Culture and Tourism, National Bureau of Statistics, UNESCO, and others). Every
  source URL is visited by script and archived as evidence, so `raw → clean → processed` is fully
  traceable.
- **Principle** — *no fabricated data*. A metric with no reliable public source is **dropped**
  rather than estimated; missing values stay `NULL` and render as "no data", never `0`.
- **Stack** — Python (pandas / numpy) for the pipeline; static HTML / CSS / vanilla JS + ECharts
  for the front end. No server and no build step: open `web/index.html` directly.
- **Quality gates** — 69 pipeline self-checks (`python tests/test_pipeline.py`).

🔗 **Live demo** — https://non-precipitating-cloud.github.io/museum-visualization/

*Source code comments and documentation are written in Chinese.*

## 一、项目简介

本项目以**中国博物馆**为对象，围绕「资源规模 → 空间分布 → 资源价值 → 公共文化服务 → 国际比较」
这条数据故事线，构建了一个可交互的可视化大屏与 5 个辅助分析页。

**项目定位：数据可视化作品，不是商业产品。** 因此：

- 技术上只使用 **Python（pandas / numpy）+ HTML / CSS / 原生 JS + ECharts**；
- **不引入** FastAPI、Redis、PostgreSQL、Docker、微服务等后端基础设施；
- 前端为**纯静态页面**，双击 `web/index.html` 即可运行，无需任何服务端。

**本项目最高优先级的原则是：绝不虚构数据。**
所有业务数值均从官方公开来源逐条转录；查不到的指标**宁可取消这张图，也不造数据**。
这条原则的具体执行情况见 [十一、数据局限性](#十一数据局限性) 与
[`docs/data_audit_report.md`](docs/data_audit_report.md)。

## 二、研究问题

整个项目围绕五个问题展开，每个可视化元素都对应其中一个：

| 编号 | 研究问题 | 主要承载图表 | 所在页面 |
|---|---|---|---|
| Q1 | 中国博物馆发展到了什么规模？ | KPI、全国博物馆数量趋势、全国馆藏趋势、全国展览趋势 | 首页 / 发展趋势 |
| Q2 | 博物馆文化资源主要分布在哪里？ | 中国博物馆数量地图、每百万人博物馆数地图、分省排名 | 首页 / 空间分布 |
| Q3 | 馆藏数量和文化价值结构有什么关系？ | 全国可移动文物等级结构、可移动文物空间集聚、馆藏排名、四象限 | 首页 / 馆藏与价值 |
| Q4 | 博物馆资源是否真正转化为公共文化服务？ | 每百万人参观人次、平均每馆参观人次、馆藏×参观散点、展览×参观散点 | 首页 / 公共文化服务 |
| Q5 | 中国博物馆放到国际范围内处于怎样的发展位置？ | 各国博物馆数量（两套口径）、每百万人博物馆数、代表性博物馆参观人次 | 首页 / 国际比较 |

## 四、数据来源

来源优先级按以下原则执行：

1. **国家级官方机构** —— 国家文物局、文化和旅游部（原文化部）、国家统计局、中国政府网；
2. **省级官方机构** —— 省级文旅厅 / 文物局、省级统计公报；
3. **博物馆官方** —— 各馆官网、官方年报、官方新闻稿；
4. **国际组织与外国官方** —— UNESCO、美国 IMLS、法国文化部、德国 IfM、韩国文化体育观光部、世界银行；
5. **权威行业报告** —— TEA/AECOM《Theme Index and Museum Index》；
6. 媒体转载**仅用于核查与补全**，且一律在台账中标注为"媒体转载官方发布"，绝不作为唯一来源。

**全部来源链接均经过程序实地访问核验**，核验结果（HTTP 状态、内容长度、抓取时间）
记录在 `data/metadata/source_verification.csv`，页面快照留证于 `data/raw/_cache/`。
完整台账见：

- `data/metadata/source_registry.csv` —— 来源登记表（机构、标题、URL、类型、年份、范围）
- `data/metadata/source_verification.csv` —— 来源核验结果（由 `scripts/collect_data.py` 生成）
- [`docs/data_sources.md`](docs/data_sources.md) —— 人读版来源说明

## 六、数据处理流程

```
官方公开来源（网页 / PDF / 年鉴表格）
        ↓  人工逐条转录，不加工
data/raw/            原始数据（保留 # 注释行说明口径，绝不覆盖）
        ↓  scripts/clean_data.py
data/clean/          规范化：省份名统一、数值类型转换、完全重复剔除
        ↓  scripts/build_dataset.py  (+ src/metrics.py)
data/processed/      分析数据集 + 8 个派生指标（KPI 同比在此真实计算）
        ↓  scripts/build_web_data.py
web/data/*.js        前端数据（NaN → null，前端显示"暂无数据"）
        ↓
ECharts 可视化 → 分析结论
```

配套脚本：

| 脚本 | 作用 |
|---|---|
| `scripts/prepare_assets.py` | 下载并本地化 ECharts 与中国省级边界 GeoJSON |
| `scripts/collect_data.py` | **实地核验**每条来源 URL 并保存页面快照 |
| `scripts/clean_data.py` | 清洗 raw → clean，输出清洗日志 |
| `scripts/build_dataset.py` | 构建分析数据集与派生指标 |
| `scripts/build_web_data.py` | 生成前端数据文件 |
| `scripts/build_dictionary.py` | 生成数据字典 |
| `scripts/data_audit.py` | **数据审计**：逐数据集统计 + 质量检查 + 交叉核对 |
| `scripts/analyze.py` | 生成分析结论（所有结论由程序计算） |
| `scripts/build_docs.py` | 生成来源说明与处理日志 |
| `scripts/run_all.py` | 一键按顺序执行以上全流程 |

详细的逐步骤处理记录（删除了几条重复、哪些值缺失、发现了什么异常）
见 [`docs/data_processing.md`](docs/data_processing.md) 与
[`docs/data_quality_report.md`](docs/data_quality_report.md)。

## 七、指标计算公式

派生指标全部在 `src/metrics.py` 中以函数实现，**缺测一律返回 NULL，绝不填 0**。

| 指标 | 中文名 | 单位 | 公式 | 缺测规则 |
|---|---|---|---|---|
| `museums_per_million_population` | 每百万人博物馆数量 | 家/百万人 | `museum_count / (population_wan / 100)` | 任一字段缺测或人口为 0 → NULL |
| `visitors_per_million_population` | 每百万人参观人次 | 万人次/百万人 | `visitors_wan / (population_wan / 100)` | 同上 |
| `average_collections_per_museum` | 平均每家博物馆馆藏 | 件(套)/家 | `collection_count / museum_count` | 任一缺测或馆数为 0 → NULL |
| `average_visitors_per_museum` | 平均每家博物馆参观人次 | 万人次/家 | `visitors_wan / museum_count` | 同上 |
| `visitors_per_exhibition` | 平均每个展览参观人次 | 万人次/个 | `visitors_wan / exhibition_count` | 任一缺测或展览数为 0 → NULL |
| `visitors_per_100k_collections` | 每十万件藏品参观人次 | 万人次/10万件 | `visitors_wan / (collection_count / 100000)` | 同上 |
| `precious_ratio` | 珍贵文物比例 | % | `precious_count / collection_count × 100` | 馆藏缺测或为 0 → NULL |

图中另有两个**由图本身计算**的量：

- **Pearson 相关系数 r**：散点图与四象限图的相关系数在**浏览器端实时计算**
  （协方差 ÷ 两标准差之积），样本数小于 3 时不予计算。所有相关系数均配文声明
  **「相关不等于因果」**。
- **同比**：KPI 的同比由 `scripts/build_dataset.py` 用相邻两年真实数值计算，
  基期数值缺测或为 0 时返回空（页面显示"—"），**不估算**。

## 八、可视化设计

完整的调色与设计依据见 [`docs/visual_design.md`](docs/visual_design.md)。

**主题**：深色底、低透明面板、蓝青为主、暖色作文化强调；克制的细线与动画。
不使用赛博朋克、满屏霓虹、过度发光。

**配色经程序校验，非凭感觉挑选：**

| 用途 | 方案 | 校验结果 |
|---|---|---|
| 区域身份（东/中/西/东北） | 蓝 `#3987e5` / 青 `#199e70` / 金 `#c98500` / 红 `#e66767` | 亮度带、彩度下限、对比度全部通过；CVD 最差全对 ΔE 9.7（8—12 底线区间），因此**全部散点图强制使用「省份直接标注 + 不同标记形状」作为二次编码** |
| 数量级（地图色阶） | 单色蓝 6 级 `#184f95 → #cde2fb` | 单调性、步距、低端对比度（2.06:1）、单一色相全部通过 |
| 文物等级（一/二/三级） | 同色阶的有序用法（等级是有序量，非分类量） | 同上 |
| "暂无数据" | 中性灰 `#21323f`，刻意脱离蓝色阶 | 与任何数值都不同，避免被误读为低值 |

**其他硬性规则**（已在本项目中执行）：

- **不使用双 Y 轴**。不同量纲的指标一律拆成多个小型趋势图（首页 2×2、发展趋势页逐张展开）。
- **类别型条形图不按数值着色**——颜色只承担"区域身份"，数值大小由长度表达。
- **文字只使用文字色令牌**，绝不使用数据系列色。
- 有 ≥2 个系列时必有图例；单系列图由标题命名，不加图例框。

标题字号更大、强调条带辉光；左右两栏为辅助信息，标题收小一档、颜色压低一级。
KPI 条压扁为背景信息，把纵向空间让给地图。

**图表类型覆盖**：折线（趋势、迷你趋势）、地图、散点（四象限）、条形（排名、国际比较）、
饼图（文物等级结构）、树图、雷达图、箱线图、热力图。

**交互**：

1. 地图指标切换（博物馆数量 / 馆藏数量 / 参观人次 / 每百万人博物馆数 / 每百万人参观人次）
2. 地图省份点击联动，底部模块与 KPI 范围徽标同步更新；点击「全国」按钮恢复
3. 四象限的 X / Y 指标可自由更换（7 个可选维度）
4. 四象限区域图例筛选（点击可开关，至少保留一个）
5. 全国趋势的口径切换
6. 国际比较的口径分组切换
7. 全部图表带 tooltip（缺测显示"暂无数据"）
8. 页面间导航

**响应式**：首页采用 1920×1080 舞台 + 等比缩放（`transform: scale`），
在任意分辨率下保持版面比例不失真；辅助页为常规滚动布局。

## 十、项目运行方法

### 环境要求

- Python 3.9+（开发环境为 3.13）
- 任意现代浏览器（Chrome / Edge / Firefox）
- 若要重新下载地图与 ECharts 资源，需要网络连接

### 快速开始（只想看效果）

直接双击打开：

```
D:\museum-visualization\web\index.html
```

地图边界（`web/assets/geo/china.js`）、ECharts 运行库（`web/assets/echarts.min.js`）
与前端数据（`web/data/museum-data.js`）均已随项目提供并已本地化，
**不需要启动任何服务、不需要联网**。

### 完整流程（从原始数据重新生成）

```bash
cd /d D:\museum-visualization       # Windows CMD
# 或 cd /d/museum-visualization     # Git Bash

pip install -r requirements.txt

python scripts/run_all.py           # 一键跑通全流程
```

`run_all.py` 依次执行：

| 步骤 | 命令 | 说明 |
|---|---|---|
| 1 | `python scripts/prepare_assets.py` | 下载 ECharts 与地图边界（可跳过，文件已存在） |
| 2 | `python scripts/collect_data.py` | 核验 59 条来源 URL 并留证 |
| 3 | `python scripts/clean_data.py` | raw → clean |
| 4 | `python scripts/build_dataset.py` | 构建分析数据集与派生指标 |
| 5 | `python scripts/build_web_data.py` | 生成前端数据 |
| 6 | `python scripts/build_dictionary.py` | 生成数据字典 |
| 7 | `python scripts/data_audit.py` | 数据审计并生成审计报告 |

也可以只跑数据部分（不需要网络）：

```bash
python scripts/clean_data.py
python scripts/build_dataset.py
python scripts/build_web_data.py
python scripts/data_audit.py
```

### 自检

```bash
python tests/test_pipeline.py
```

检查：派生指标公式与边界情形（除零、缺测保持 NULL）、CSV 结构完整性、
前端数据文件中不含 NaN、口径分组未被混用。

## 十一、数据局限性

本项目在数据审计中发现了以下限制，**全部如实记录，不做任何掩盖或"技术性修补"**：

### 1. 存在两套互不兼容的博物馆统计口径

| 口径 | 发布方 | 含义 | 2019 年数值 | 2024 年数值 |
|---|---|---|---|---|
| 备案博物馆 | 国家文物局 | 登记备案的博物馆（含国有与非国有） | 5,535 **家** | 7,046 **家** |
| 公报口径博物馆 | 文化和旅游部 | 文物机构中的博物馆（含文物商店等并列机构） | 5,132 **个** | 口径已变更 |

两套数字**含义不同，不可混用、不可互相换算**。本项目在全部图表中**分列展示**，
并在图注中逐处标注。2022 年起，文化和旅游部公报进一步把口径改为
「文物系统管理的国有博物馆」，形成**口径断点**，因此趋势曲线在该处**断开而不平滑、不补齐**。

### 2. 分省「博物馆珍贵文物数量」不可得

- 《中国统计年鉴》表 23-28（分地区博物馆基本情况）**没有珍贵文物字段**；
- 《文化和旅游发展统计公报》公布的一级 / 二级 / 三级文物是**「文物机构」口径**
  （文物机构 = 博物馆 + 文物保护管理机构 + 文物商店 + 其他），
  **不能当作"博物馆珍贵文物"使用**。这一点已通过公报原文逐句核实。

**因此本项目取消了原计划的「馆藏规模 × 珍贵文物比例」分省四象限图**，改用：

- **第一次全国可移动文物普查**（2016 年 10 月 31 日时点）的真实等级结构数据；
- 把四象限的两个维度换成**真实可得**的指标（默认：博物馆数量 × 每百万人博物馆数），
  并保留 7 个可选维度。

### 3. 分省可移动文物只有前五名

国家《第一次全国可移动文物普查数据公报》正文**只列出数量最多的五个省市**，
其余省份的完整表格以图片形式存在、无法提取。本项目**只呈现可获取的省份**，
并用「其余省份合计」（全国总量 − 五省之和）展示集中度，
**明确标注该差额不是官方逐省数值，不可反推任一省份**。

### 4. 分地区表合计 ≠ 全国数

审计发现分省数据的合计与全国行存在系统性差额，例如：

| 指标 | 分省合计 | 全国数 | 差额 | 差额占比 | 原因 |
|---|---|---|---|---|---|
| 2022 年 博物馆数量 | 6,086 | 6,091 | −5 | −0.08% | 未分配到省的中央级单位等 |
| 2022 年 博物馆文物藏品 | 4,347.85 万 | 4,691.61 万 | −343.76 万 | −7.33% | 统计范围差异 |
| 2022 年 博物馆参观人次 | 56,465 万 | 45,647 万 | +10,818 万 | **+23.70%** | **口径变更**（见上） |
| 2022 年 年末人口 | 140,975 万 | 141,175 万 | −200 万 | −0.14% | 全国含现役军人等 |

**结论：不能把分省数据加总当作全国数据。** 本项目全国趋势图一律直接使用
官方公布的全国数，分省图一律使用分省表本身的数，两者不互相推算。

### 5. 国际比较的口径与年份都不一致

- UNESCO 报告明确指出：博物馆计数"虽基于同一定义，但各国执行方式不同"，
  并点名中国的 1,030 家"明显低于网上其它估计（5000+）"；
- 同一个**法国**，官方口径 1,220 家（法定称号 `musée de France`），UNESCO 口径 4,811 家，**相差近 4 倍**；
- 同一个**中国**，官方备案口径 7,046 家，UNESCO 口径 1,030 家；
- 美国 IMLS 的 35,144 家把植物园、动物园、水族馆、历史学会、科学中心、儿童博物馆
  都算作 museum。

**因此本项目拒绝把不同国家不同口径的数字放进一张"全球排名"图。**
国际比较页提供**口径切换**，并专门做了一张「口径差异对照表」来展示这种不可比性。
唯一具备严格可比性的是 TEA/AECOM 榜单（同一机构、同一方法、同一年度）。

### 6. 时间范围

《文化发展统计公报》自 2013 年才开始发布，2010—2012 年缺少官方公开的博物馆统计，
故时间序列自数据实际可得年份开始，**不向前补齐**。

### 7. 分省数据的转录方式

《中国统计年鉴》表 23-28 与表 2-5 的原文为 **JPG 图片表格**，数值由人工逐格转录。
本项目通过**交叉验证**控制转录风险：分省合计与独立来源（文化和旅游部公报的全国数）
在 2020、2021 年完全吻合（博物馆 5,452 / 5,772，藏品 4,319.09 / 4,664.83 万），
说明转录正确；2022 年的差异已定位为**口径变更**而非转录错误。

### 8. 缺失值处理

**不使用"把 NaN 一律填 0"**。缺失按语义区分「未统计 / 未公开 / 不适用 / 真实的 0」；
无法判断时保留 NULL，可视化统一显示**「暂无数据」**。

## 十二、项目结论

> 以下结论**全部由真实数据计算得出**，每条都标注了数据依据。
> 本项目严格区分**事实 / 描述 / 相关关系 / 因果关系**，不做超出数据的推断。

### 结论 1：中国博物馆已形成相当的规模，且仍在增长（事实）

- 截至 2024 年底，全国**备案博物馆 7,046 家**，较上年增加 213 家（**+3.1%**）；
- 2024 年接待观众 **14.9 亿人次**，较上年增长 **15.5%**；
- 举办陈列展览 **4.3 万个**，较上年增长 **7.5%**；
- 免费开放率达 **91.46%**。

（来源：国家文物局，见 `data/metadata/source_registry.csv` 中 `SRC_NCHA_2024`）

### 结论 2：发展过程存在明显的冲击与恢复（事实）

全国博物馆参观人次在 **2020 年出现断崖式下降**（备案口径由 2019 年的 12.27 亿人次
降至 5.4 亿人次），随后逐年恢复，2023 年达到 12.9 亿人次（创历史新高），
2024 年进一步升至 14.9 亿人次。这是数据中的客观事实，项目中**未做任何平滑或剔除**。

### 结论 3：资源分布高度集中于少数地区（事实 + 描述）

- 2022 年博物馆数量最多的省份是**山东（665 家）、浙江（432 家）、河南（400 家）**；
- 从**可移动文物**看，集中度更为突出：在普查登录文物的**实际数量 64,073,178 件**中，
  可获取的**五省市合计占 51.42%**，其中**北京一地即占 18.13%**；
- 第一位与末位省份（山东 665 家 vs 西藏 15 家）相差约 **44.3 倍**。

> **口径细节（容易算错的地方）**：普查公布的全国可移动文物总量是 **108,154,907 件/套**，
> 但其中包含**各级综合档案馆纸质历史档案 81,544,000 卷/件**。
> 公报给出的省级占比是相对「登录文物实际数量 **64,073,178 件**」计算的
> （验算：北京 11,615,758 ÷ 64,073,178 = 18.13%，与公报一致）。
> 若误用 108,154,907 作分母，北京会算成 10.74%，与公报不符。
> **本项目统一使用 64,073,178 作分母，并在代码注释中写明原因。**

### 结论 4：考虑人口后，空间格局确实会发生变化（事实 + 相关关系）

**绝对规模排名与人口标准化排名并不一致：**

| 口径 | 前 5 位 |
|---|---|
| 博物馆**数量**（绝对规模） | 山东 665、浙江 432、河南 400、江苏 373、广东 340 |
| 每百万人博物馆**数量**（人口标准化） | 甘肃 9.23、宁夏 8.79、陕西 8.11、内蒙古 6.91、浙江 6.57 |

甘肃、宁夏、陕西、内蒙古这些**绝对数量并不靠前**的省份，在人口标准化后进入前列。

更直接的证据是：**博物馆数量与每百万人博物馆数量之间的 Pearson 相关系数仅为
r = 0.22（几乎无线性相关，31 个省份）**。这说明**总量指标与密度指标承载的是
几乎不同的信息，只看总量会掩盖人口因素的影响**——这是本项目采用
"绝对规模 + 标准化指标"双轨分析的原因。

### 结论 5：资源供给与公众使用之间存在正相关，但不能解释为因果（相关关系）

2022 年 31 个省级行政区截面数据的 Pearson 相关系数（由页面实时计算）：

| 变量对 | r | 强度 |
|---|---|---|
| 展览数量 × 参观人次 | **0.71** | 中等偏强正相关 |
| 博物馆数量 × 参观人次 | **0.69** | 中等偏强正相关 |
| 馆藏数量 × 参观人次 | **0.40** | 弱到中等正相关 |

值得注意的是：**馆藏规模与参观人次的相关性（0.40）明显弱于展览数量与参观人次的相关性
（0.71）**。一个可能的描述性解读是"观众规模与展览供给的关联比与馆藏存量的关联更强"，
但本项目**不做因果解释**。

**必须强调：以上都是相关关系，不是因果关系。** 截面数据无法区分
「资源带动服务」与「需求带动资源」两个方向；观众规模还受免费开放政策、
地理位置、人口基数等多种因素影响。本项目**不把任何派生指标称为"管理绩效排名"**。

### 结论 6：中国博物馆在国际上处于规模前列，但口径差异使严格排名不成立（事实 + 限制）

- 在 UNESCO 统一口径（2019）下，中国的 1,030 家排在全球中游；
- 在中国官方备案口径（2024）下，中国 7,046 家；
- 差异源于**定义与统计范围**，而非某一方"更正确"；
- 在 **TEA/AECOM 2023 全球博物馆参观人次榜**（唯一严格可比的口径：同一机构、
  同一方法、同一年度）上，**全球前 20 中有 7 家中国博物馆**：

  | 全球排名 | 博物馆 | 2023 年参观人次 |
  |---|---|---|
  | 3 | 中国国家博物馆 | 675.7 万 |
  | 7 | 中国科学技术馆 | 531.5 万 |
  | 8 | 南京博物院 | 500.7 万 |
  | 10 | 苏州博物馆 | 485.2 万 |
  | 13 | 湖南博物院 | 439.8 万 |
  | 14 | 湖北省博物馆 | 430.0 万 |
  | 16 | 广东省博物馆 | 400.0 万 |

  该报告同时给出：2023 年全球前 20 博物馆合计约 9,976 万人次，较 2022 年增长 65.9%，
  恢复至 2019 年的 94.6%。

### 结论 7：本项目在数据获取上主动做了减法（方法性结论）

以下模块因**缺乏可靠公开数据**而**主动取消或降级**，而不是用估算值填充：

| 原计划模块 | 处理 | 原因 |
|---|---|---|
| 省级「馆藏规模 × 珍贵文物比例」四象限 | **取消**，改为可得的指标组合 | 分省博物馆珍贵文物数据不可得，且公报口径不可用 |
| 各省珍贵文物数量排名 | **取消** | 同上 |
| 馆藏历史时期结构（秦汉唐宋元明清） | **取消** | 无全国统一公开的分类数据 |
| 全国文物来源省份 → 博物馆 Sankey | **取消** | 无稳定完整的全国配对数据 |
| 国际比较的"全球排名" | **降级**为口径分组比较 | 各国定义与年份不一致 |

## 十三、后续扩展

1. **补齐分省时间序列**：获取《中国文化文物统计年鉴》的历年分地区表，把分省数据从
   2020—2022 扩展到更长时段，即可做面板数据分析；
2. **接入官方开放数据接口**：国家文物局"全国博物馆年度报告信息系统"的公开接口
   （`nb.ncha.gov.cn/je/api/...`）可用，但目前**不暴露珍贵文物字段**，若将来开放即可补齐；
3. **补充分省珍贵文物**：若各省陆续发布可移动文物普查分省公报，即可恢复原计划的
   珍贵文物比例四象限；
4. **增加馆际比较维度**：补充各代表性博物馆的建筑面积、展览数、教育活动数，
   做更完整的"博物馆服务能力"画像；
5. **时间维度扩展到动态**：把年份切换做成时间轴播放动画；
6. **无障碍增强**：为色觉障碍用户提供纹理填充（本项目已用"颜色 + 形状 + 直接标注"
   三重编码，仍可进一步补充纹理通道）。
