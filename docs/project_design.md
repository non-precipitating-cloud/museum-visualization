# 项目设计文档

《中国博物馆文化资源与公共文化服务的多维可视化分析》

---

## 一、设计起点：先定问题，再定图表

本项目遵循一个反向流程：

```
不是「我有什么数据 → 我画什么图」
而是「我要回答什么问题 → 需要什么数据 → 数据是否存在 → 存在才画图」
```

这条流程直接导致了项目中**主动取消 5 个模块**（见第六节）——因为"数据不存在"。

---

## 二、数据故事线

```
    【资源规模】      全国博物馆有多少？馆藏多少？展览多少？
         ↓
    【空间分布】      资源集中在哪里？考虑人口后格局是否变化？
         ↓
    【资源价值】      馆藏由什么等级结构构成？分布在哪些省份？
         ↓
    【公共服务】      资源有没有变成公众可用的服务？
         ↓
    【国际比较】      放到世界范围内是什么位置？
```

**讲解与分页顺序**严格按这条线（Q1 → Q2 → Q3 → Q4 → Q5）展开；
但**首页大屏并不按这条线的顺序组织**，它按视觉层级排布：KPI 条压扁为背景信息，
中国地图为第一主视觉（面积约占一半），全国发展趋势、资源结构四象限、
公共文化服务与国际比较作为辅助——大屏的视觉层级与故事线顺序**并不相同**。

---

## 三、五个研究问题与图表映射

完整的图表—数据集—字段—来源映射见 `data/metadata/chart_data_mapping.csv`。

### Q1：中国博物馆发展到了什么规模？

| 图表 | 类型 | 为什么选这个类型 |
|---|---|---|
| KPI × 5（博物馆数量 / 馆藏 / 珍贵文物 / 参观人次 / 展览） | 数字块 | 规模问题需要**一个明确的主数字**，不是图 |
| 全国博物馆数量趋势 × 2（两套口径） | 折线 | 变化随时间 → 折线；两套口径**分列**而不是画在一张图上 |
| 全国馆藏文物趋势 × 2 | 折线 | 同上 |
| 全国参观人次趋势 × 2 | 折线 | 同上 |
| 全国陈列展览趋势 | 折线 | 同上 |

> **口径纪律**：不同量纲的四个指标**不使用双 Y 轴**，而是拆成 4 张小型趋势图。

### Q2：博物馆文化资源主要分布在哪里？

| 图表 | 类型 | 为什么选这个类型 |
|---|---|---|
| 中国博物馆数量地图 | 分级统计图（choropleth） | 空间分布问题的标准形式 |
| 每百万人博物馆数量地图 | 分级统计图 | 回答"考虑人口后格局是否变化" |
| 各省博物馆数量排名 | 横向条形 | 比较大小 → 长度最准确 |
| 各省参观人次排名 | 横向条形 | 同上 |
| 每百万人博物馆数量排名 | 横向条形 | 同上 |
| 每百万人参观人次排名 | 横向条形 | 同上 |

> **设计要点**：地图用**单色顺序色阶**（不是彩虹色）；条形图**不按数值着色**，
> 颜色只表示"区域身份"。

### Q3：馆藏数量和文化价值结构有什么关系？

| 图表 | 类型 | 为什么选这个类型 |
|---|---|---|
| 全国可移动文物等级结构 | 饼图（扇形图，非环形） | 部分与整体 + 有序分类（一/二/三级）→ 用**同色阶的有序用法**；三档合计就是「珍贵文物」这个整体，实心扇形的面积与占比一一对应 |
| 可移动文物空间集聚 | 横向条形 + 占比标注 | 展示集中度（前五省 + 其余合计） |
| 各省馆藏数量排名 | 横向条形 | 比较大小 |
| 平均每家博物馆馆藏排名 | 横向条形 | 标准化后的结构指标 |
| **省级博物馆资源结构四象限** | 散点 + 均值线 | **多维度关系** → 散点；均值线切出四个象限便于解读 |

> **说明**：原计划的「馆藏规模 × 珍贵文物比例」四象限因数据不可得而**取消了 Y 轴的原设计**，
> 改为默认「博物馆数量 × 每百万人博物馆数」并保留 7 个可切换维度。
> 详见「馆藏与价值」页的省级博物馆资源结构四象限图。

### Q4：博物馆资源是否真正转化为公共文化服务？

| 图表 | 类型 | 为什么选这个类型 |
|---|---|---|
| 每百万人参观人次排名 | 横向条形 | 人口标准化后的服务强度 |
| 平均每家博物馆参观人次 | 横向条形 | 机构视角的服务强度 |
| 平均每个展览参观人次 | 横向条形 | 展览视角的服务强度 |
| 馆藏规模 × 参观人次散点 | 散点 + 均值线 + 相关系数 | **关系**问题 → 散点 |
| 展览供给 × 参观人次散点 | 散点 + 均值线 + 相关系数 | 同上 |

> **表述纪律**：这些是**描述性指标**，页面明确写"不构成管理绩效排名"；
> 相关系数旁明确标注**"相关不等于因果"**。

### Q5：中国博物馆放到国际范围内处于怎样的发展位置？

| 图表 | 类型 | 为什么选这个类型 |
|---|---|---|
| 各国博物馆数量（UNESCO 统一口径） | 横向条形 | 同一年份同一来源，可比性最好 |
| 各国自报官方口径 | 横向条形 + 口径切换 | 展示另一种口径下的图景 |
| 口径差异对照表 | 表格 | **口径差异本身就是结论**，用表格最清楚 |
| 每百万人博物馆数量 | 横向条形 | 人口标准化 |
| 全球代表性博物馆参观人次（TEA/AECOM 2023） | 横向条形 | 同机构同方法同年 → 唯一严格可比的排名 |
| 代表性博物馆（各馆官方口径） | 横向条形 + tooltip 逐条口径说明 | 展示中国博物馆的个体位置 |

## 四、视觉层级设计（首页）

```
┌──────────────────────────────────────────────────────────────┐
│  标题 + 主导航                        [当前范围] [数据年份]     │
├──────────────────────────────────────────────────────────────┤
│  KPI 博物馆数 │ 馆藏 │ 珍贵文物 │ 参观人次 │ 展览数量           │
├───────────────────────────────┬──────────────────────────────┤
│                               │                              │
│   ★ 中国地图（第一主视觉）      │   全国发展趋势（2×2 小趋势）    │
│   5 个指标可切换 / 可点击联动   │                              │
│                               │                              │
├───────────────────────────────┴──────────────────────────────┤
│   ★★ 省级博物馆资源结构四象限  │  数据洞察（程序计算）           │
├───────────────────────────────┬──────────────────────────────┤
│   公共文化服务                 │   国际比较                    │
└───────────────────────────────┴──────────────────────────────┘
```

**层级原则：**

- **地图最大** —— 占首页面积最大的一块，且是唯一允许"缩放/点击"的图；
- **四象限第二重要** —— 通栏宽度，右侧专门留一栏放"数据洞察"；
- **KPI 明显** —— 5 个等宽数字块，每个带年份、口径与同比；
- **国际比较位于底部** —— 不抢占主视觉。

**避开的坑**：所有图表一样大、图表塞满屏幕、为了炫技加装饰。

## 五、交互设计

| 交互 | 位置 | 目的 |
|---|---|---|
| 地图指标切换（5 个 Tab） | 首页地图 | 让同一空间格局在不同指标下被反复审视 |
| 地图省份点击 | 首页地图 | 与底部模块和范围徽标联动；点"全国"恢复 |
| 四象限维度切换（X/Y 各 7 个选项） | 首页四象限 | 让读者自己探索指标间关系 |
| 四象限区域筛选（可开关的图例芯片） | 首页四象限 | 聚焦某一区域 |
| 全国趋势口径切换 | 首页 + 发展趋势页 | 直面"两套口径"这件事 |
| 国际比较口径切换 | 国际比较页 | 直面"口径不可比"这件事 |
| tooltip（全部图表） | 全局 | 缺测显示"暂无数据" |
| 页面导航 | 全局 | 大屏 ⇄ 5 个辅助页 ⇄ 数据说明页 |

**关键设计**：把"口径"做成**可切换的交互控件**，而不是藏在脚注里——
这是本项目最想传达的一点。

## 六、主动取消 / 降级的模块（设计上的减法）

| 原计划模块 | 处理 | 数据层面的原因 |
|---|---|---|
| 省级「馆藏规模 × 珍贵文物比例」四象限 | **取消 Y 轴原设计**，改用可得指标组合 | 年鉴分省表无珍贵文字段；公报的一/二/三级文物是"文物机构"口径 |
| 各省珍贵文物数量排名 | **取消** | 同上，仅广东一省有值 |
| 各等级文物（一/二/三级）分省比较 | **取消** | 同上 |
| 全国文物来源省份 → 博物馆 Sankey | **取消** | 无稳定完整的全国配对数据 |
| 馆藏历史时期结构（秦汉唐宋元明清） | **取消** | 无全国统一口径的历史时期分类数据 |
| 国际比较做成"全球排名" | **降级**为口径分组比较 | 各国定义、年份、范围不一致 |

**每一项的处理方式都是"取消"，而不是"用估算值补齐"或"用示例数据代替"。**

## 七、项目规模

| 项目 | 数量 |
|---|---|
| 原始数据集 | 8 个（280 条原始记录） |
| 分析数据集 | 6 个（187 条分析记录，65 个字段） |
| 派生指标 | 7 个 |
| 数据来源 | 59 条（全部经程序核验） |
| 核心 KPI | 5 个 |
| 分析图表 | 27 张 |
| 页面 | 1 个主大屏 + 5 个辅助分析页 + 1 个数据说明页 |

**核心可视化元素的规模控制**：
首页实际呈现 **5 KPI + 6 个核心图表区块**（地图 / 趋势组 / 四象限 / 服务 / 国际 + 洞察栏），
辅助页把趋势组与排名组展开为 27 张完整图表，**没有为凑数而重复的图**。
