# 数据质量报告

《中国博物馆文化资源与公共文化服务的多维可视化分析》

> **本项目的原则：数据质量问题只记录、不静默修改。**
> 所有处置方式都在本文中写明，可被审计。

自动检查的结果由 `scripts/data_audit.py` 生成，写入：

- `data/metadata/data_quality_report.csv` —— 机读版问题清单
- `docs/data_audit_report.md` —— 完整体检报告

---

## 一、自动检查项目与结果

`scripts/data_audit.py` 会对每个数据集逐项检查以下规则：

| 检查项 | 规则 | 结果 |
|---|---|---|
| 重复记录 | 整行内容完全相同 | **0 条** |
| 年份异常 | 年份不在 1949—2100 | **0 条** |
| 负数 | 任何计数类指标为负 | **0 条** |
| 除零 | `population_wan = 0` 或 `museum_count = 0` | **0 条** |
| 逻辑矛盾 | `precious_count > collection_count` | **0 条** |
| 比例越界 | `precious_ratio > 100%` | **0 条** |
| 省份名称 | 不在标准 31 省清单内 | **0 条** |
| 场馆名称重复 | 博物馆名称重复 | **0 条** |

**结论：自动检查未发现数据质量问题（0 条）。**

> 说明：本项目的数据规模较小（280 条原始记录）且为人工逐条转录，
> 录入纪律较好；这**不等于**数据没有局限——局限在第三节。

## 二、开发过程中实际发现并处置的问题

以下是项目过程中**真实出现过**的问题。全部**记录在案，处置方式公开**。

### 问题 1：原始 CSV 中混入半角逗号导致列错位 ⚠️ 已修复

**现象**：`clean_data.py` 在读取原始数据时报
`Error tokenizing data. C error: Expected 14 fields in line 23, saw 15`。

**定位**：原始转录时，文本字段（如"（6,782家）""35,000""2,563,820人"）
里使用了**半角逗号**，而该字段没有加引号，导致 CSV 解析时多切出一列。

**处置**：
1. 修正了出问题的字段（改用无千分位写法或全角标点）；
2. **给 `clean_data.py` 增加了结构预检**：捕获解析异常时，用 `csv` 模块
   逐行比对列数，**直接指出是第几行、期望几列、实际几列**，并提示
   "最常见的成因：文本字段里写了半角逗号而没加引号"；
3. **给 `tests/test_pipeline.py` 增加了专项检查**：原始转录文件
   **不允许出现带引号的字段**——一旦出现就说明有半角逗号混进了文本列，
   属于潜在结构隐患。

**为什么这样处理而不是直接改数据**：这类错误如果只改数据、不加检查，
下次转录还会再犯。加检查才是真正的修复。

### 问题 2：分省数据合计 ≠ 全国数据 ⚠️ 已确认为真实差异，如实保留

**现象**：审计发现分省数据的合计与对应的全国数不一致。

| 指标 | 分省合计 | 全国数 | 差额 | 差额占比 |
|---|---|---|---|---|
| 2020 年 博物馆数量 | 5,447 | 5,452 | −5 | −0.09% |
| 2021 年 博物馆数量 | 5,767 | 5,772 | −5 | −0.09% |
| 2022 年 博物馆数量 | 6,086 | 6,091 | −5 | −0.08% |
| 2020 年 博物馆文物藏品 | 3,981.68 万 | 4,319.09 万 | −337.41 万 | −7.81% |
| 2021 年 博物馆文物藏品 | 4,322.99 万 | 4,664.83 万 | −341.84 万 | −7.33% |
| 2022 年 博物馆文物藏品 | 4,347.85 万 | 4,691.61 万 | −343.76 万 | −7.33% |
| 2020 年 参观人次 | 52,036 万 | 52,652 万 | −616 万 | −1.17% |
| 2021 年 参观人次 | 73,757 万 | 74,850 万 | −1,093 万 | −1.46% |
| **2022 年 参观人次** | **56,465 万** | **45,647 万** | **+10,818 万** | **+23.70%** |
| 2020/2021/2022 年末人口 | 141,013 / 141,060 / 140,975 万 | 141,212 / 141,260 / 141,175 万 | −199 / −200 / −200 万 | −0.14% |

**处置：不做任何调和，如实记录，并在项目纪律中消化。**

1. **2020、2021 年的小差额（−5、−1%左右）是正常现象** ——
   分地区表的合计与全国行本身就不相等（存在未分配到省的中央级单位）。
   **值得注意的是：这组"接近吻合"反而证明了我们的转录是准确的**
   （因为分省数据是人工从年鉴 JPG 表格逐格转录的，如果转录错了，合计不可能这么接近）。

2. **2022 年参观人次高出 +23.70%，是口径变更而非数据错误**：
   - 文化和旅游部**自 2022 年起**把公报中的博物馆口径改为
     「**文物系统管理的国有博物馆**」（2022 年公报给出 3,782 个、接待观众 45,647 万人次）；
   - 而《中国统计年鉴》表 23-28 **仍沿用「博物馆」口径**（2022 年为 6,091 个、57,048 万人次）。

   **这处差异从数据上印证了本项目反复强调的口径断点确实存在。**

3. **项目纪律**：因此本项目规定——
   **全国趋势图一律直接使用官方公布的全国数；分省图一律使用分省表本身的数；
   两者不互相推算、不互相校验后强行对齐。**

### 问题 3：分省珍贵文物数量几乎完全不可得 ⚠️ 已降级处理

**现象**：`province_museums.csv` 的 `precious_count` 字段，
**93 条记录中只有 1 条有值**（广东 2022 年 87,042 件/套），
其余 92 条为空。

**原因（经核实，不是我们没找到）**：

1. 《中国统计年鉴》表 23-28「分地区博物馆基本情况」**根本没有这个字段**；
2. 《文化和旅游发展统计公报》公布过一级/二级/三级文物数，
   但**逐字核对公报原文后确认是「文物机构」口径**：

   > "年末全国**文物机构**拥有文物藏品 4455.91 万件……其中，博物馆文物藏品
   > 3329.38 万件……文物藏品中，**一级文物 10.98 万件……二级文物 76.47 万件……
   > 三级文物 363.16 万件**。"——2016 年文化发展统计公报

   文物机构 = 博物馆 + 文物保护管理机构 + **文物商店** + 其他，
   **把文物商店的藏品当作博物馆珍贵文物是口径错误**；

3. 国家文物局「全国博物馆年度报告信息系统」的公开接口在抽查的 200 条记录中，
   珍贵文物相关字段**全部为 null**，不对外暴露。

**处置**：
- **保留这一列**（并让它保持为空），以如实反映"该指标不可得"；
- **取消**原计划的「馆藏规模 × 珍贵文物比例」分省四象限与「各省珍贵文物排名」；
- 改用 **第一次全国可移动文物普查**（2016 时点）的真实等级结构数据；
- 在数据字典与 README 中**两处说明**该字段为何不可用。

### 问题 4：普查公报只公布分省前五名 ⚠️ 已如实标注

**现象**：可移动文物普查的分省数据，国家公报正文**只列出数量最多的五个省市**
（北京、陕西、山东、河南、山西），其余省份的完整表格以图片形式存在、无法提取。

**处置**：
- 图表**只呈现可获取的 5 个省份**；
- 补一条「**其余省份合计**」，并**明确标注它的来源**：
  `全国总量 − 五省之和` 得到的差额；
- 页面写明：**"该差额不是官方公布的逐省数值，仅用于展示集中度，
  **不可反推任一省份的具体数量**"**。

### 问题 5：港澳台无数据 ⚠️ 显示为"暂无数据"而非 0

**现象**：本项目未获得港澳台可比的博物馆统计公开数据（口径与统计体系不同）。

**处置**：
- 地图上**画出其边界**（地理事实），填充为**中性的"暂无数据"色 `#21323f`**；
- tooltip 显示"本项目统计范围内无此地区数据（暂无数据）"；
- 图注中明确说明**不参与任何统计**；
- **绝不填 0**，因为 0 会被误读为"没有博物馆"，而事实是"没有可比数据"。

> 注：台北故宫博物院作为**代表性博物馆案例**出现在国际比较页，
> 数据来自其官方统计（民国 114 年度 / 2025 年，参观 2,426,842 人次）。

### 问题 6：全国年度序列存在缺测年份 ⚠️ 保持为空，不补齐

**现象**：备案博物馆口径的年度序列中，部分年份的部分指标官方未公布：

| 年份 | 博物馆数量 | 参观人次 | 展览数量 |
|---|---|---|---|
| 2015 | 4,692 | *未公布* | *未公布* |
| 2016 | 4,873 | 9.0 亿 | *未公布* |
| 2017 | 5,136 | *未公布* | *未公布* |
| 2018 | 5,354 | 11.26 亿 | 2.6 万 |
| 2019—2024 | 完整 | 完整 | 完整 |

**处置**：
- 缺测**保持为空（NULL）**，折线图使用 `connectNulls: false`，**曲线在该处断开**；
- **不插值、不补齐、不用邻近年份顶替**；
- **不向前扩展到 2010—2012 年**：官方《文化发展统计公报》自 2013 年才开始发布，
  2010—2012 年没有官方公开的博物馆统计。

### 问题 7：2017 年备案博物馆数的年份归属存在两种说法 ℹ️ 已标注

**现象**：国家文物局局长刘玉珠在 2019 年 3 月两会"部长通道"表示
"到 **2017 年年底**，全国在各级政府备案的博物馆达到了 5136 家"；
但也有报道把 5136 家作为 2018 年初全国文物局长会议时的"截至目前"数据。

**处置**：
- 在 `source_registry.csv` 的 `note` 字段中**如实记录这两种说法**；
- 在数据字典与 README 中标注该年份存在两说；
- **不擅自选择其中一种并当成确定事实**。

### 问题 8：各馆参观人次的统计口径互不相同 ℹ️ 逐条标注

**现象**：代表性博物馆的官方数据在年份与统计范围上并不一致：

| 博物馆 | 数值 | 口径差异 |
|---|---|---|
| 韩国国立中央博物馆 | 1,091 万（2024） | **中央馆 + 全部所属地区馆**的合计，不是单馆 |
| 上海博物馆 | 657.9 万（2024） | **人民广场馆与东馆**两处合计 |
| 大英博物馆 | 650 万 | **财年** 2024/25 |
| 东京国立博物馆 | 256.4 万 | **日本财年**（令和 6 年度） |
| 台北故宫博物院 | 242.7 万（2025） | **民国 114 年度** |
| 湖北省博物馆 | 500 万+ | 官网表述为"超过 500 万人次"，非精确值 |
| 故宫博物院 | 1,760 万+ | 报道表述"超 1760 万"，非精确值 |
| 南京博物院 | *未获取到* | 年报 PDF 超过抓取上限 |

**处置**：
- 数据集中为每一行设 `year_note`（年份口径）与 `caliber_note`（统计范围）两列，
  **逐条说明**；
- 图表 tooltip 中显示这两个字段；
- 图下方明确声明：**本图不能当作排名**（与 TEA/AECOM 榜单不同，后者同机构同方法同年）；
- 对"超过 X 万"这类表述，**按来源原样标注为"超"，不做精确化处理**。

## 三、数据本身固有的局限（无法通过处理消除）

1. **分省数据只有 2020—2022 三年** —— 《中国文化文物统计年鉴》分地区表需付费，
   这是本项目时间维度的主要限制；
2. **可移动文物普查只有一个时点（2016 年 10 月 31 日）** —— 是存量数据，无法看趋势；
3. **普查口径 ≠ 博物馆口径** —— 普查对象是全部国有单位（含档案馆、图书馆、
   宗教场所、国企等），**大于**"博物馆馆藏"，两者不可混用；
4. **国际数据年份与定义不一致** —— 已在「国际比较」页用口径切换与对照表显式呈现；
5. **分省数据由人工从 JPG 表格逐格转录** —— 已用交叉验证控制风险（见问题 2），
   但仍有残余转录风险；
6. **TEA/AECOM 榜单是商业报告** —— 虽被业界广泛引用且方法一致，
   但非政府统计，已在来源台账中标为"三级"。

## 四、结论

- **自动检查层面**：0 条数据质量问题；
- **过程层面发现并处置的问题**：8 项，全部记录在案、处置方式公开；
- **主动降级/取消的模块**：5 项，原因是数据不可得，**而非实现困难**。

本项目可以给出的最有力承诺是：

> **任何一个显示在页面上的数字，都能向上追溯到具体的来源 URL、
> 具体的字段、具体的计算公式，以及"它为什么是这个口径"的说明。**
