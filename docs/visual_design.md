# 可视化设计规范与配色校验记录

---

## 一、设计目标

**主题**：中国博物馆文化资源
**风格**：现代、专业、克制、有文化感
**画布**：1920 × 1080（16:9），等比缩放适配任意屏幕

**明确不做**：赛博朋克、满屏霓虹、过度发光、大量装饰、满屏动画、所有图表一样大。

---

## 三、配色方案与校验

配色**不是凭感觉挑的**，而是先按"颜色承担什么职责"分类，再用脚本校验。

### 3.1 分类色：区域身份（东部 / 中部 / 西部 / 东北）

用于散点图、四象限、排名条形图的**身份编码**。

| 区域 | 色值 | 含义 |
|---|---|---|
| 东部 | `#3987e5` | 蓝 |
| 中部 | `#199e70` | 青 |
| 西部 | `#c98500` | 金（文化强调色） |
| 东北 | `#e66767` | 红 |

**校验命令与结果**（针对本项目的深色面 `#101f30`，并按散点图要求检查全部色对）：

```
node scripts/validate_palette.js "#3987e5,#199e70,#c98500,#e66767" \
     --mode dark --surface "#101f30" --pairs all

  [PASS] Lightness band         all 4 inside L 0.48–0.67
  [PASS] Chroma floor           all 4 >= 0.1
  [WARN] CVD separation         worst all-pairs #e66767↔#199e70 ΔE 9.7 (protan)
  [PASS] Contrast vs surface    all 4 >= 3:1
  → ALL CHECKS PASS
```

**关于那条 WARN 的处理**：色觉障碍下最差色对（红 ↔ 青）分离度 ΔE 9.7，
落在 8—12 的"底线区间"。该区间**只有配合二次编码才合规**，因此本项目在
**所有散点类图表上强制加上第二、第三重编码**：

1. **省份名称直接标注**（不依赖颜色识别身份）；
2. **不同标记形状**：东部=圆形、中部=三角、西部=菱形、东北=方形。

这样即使完全无法分辨颜色，读者依然能读出每个点的区域归属。

### 3.2 顺序色阶：数量级（地图）

用于地图的连续数量编码。**单色、单一色相**，绝不用彩虹色。

| 级 | 色值 | 相对面板对比度 |
|---|---|---|
| 1 | `#184f95` | 2.06:1 |
| 2 | `#256abf` | 3.09:1 |
| 3 | `#3987e5` | 4.58:1 |
| 4 | `#6da7ec` | 6.65:1 |
| 5 | `#9ec5f4` | 9.32:1 |
| 6 | `#cde2fb` | 12.59:1 |

**校验结果**：

```
node scripts/validate_palette.js "#184f95,#256abf,#3987e5,#6da7ec,#9ec5f4,#cde2fb" \
     --ordinal --mode dark --surface "#101f30"

  [PASS] Lightness monotone     steps read light→dark
  [PASS] Adjacent ΔL            all gaps >= 0.06
  [PASS] Light-end contrast     #184f95 at 2.06:1 vs surface
  [PASS] Single hue             hue spread 4°
  → ALL CHECKS PASS
```

更暗的一级 `#0d366b` 只有 1.39:1，与面板几乎融在一起，**已弃用**。

### 3.3 有序色阶：文物等级（一 / 二 / 三级）

文物等级是**有序量**（一 > 二 > 三），不是分类量，因此**不使用分类色**，
而是使用上述蓝色阶的有序用法：等级越高、颜色越亮。

| 等级 | 色值 |
|---|---|
| 一级文物 | `#cde2fb` |
| 二级文物 | `#9ec5f4` |
| 三级文物 | `#6da7ec` |

### 3.4 缺测色

| 角色 | 色值 | 说明 |
|---|---|---|
| 暂无数据 | `#21323f` | **刻意脱离蓝色阶**的中性灰蓝 |

这一点很重要：如果缺测沿用色阶的最低级，读者会把"没有数据"误读成"数值很低"。
本项目在地图上把港澳台（本项目统计范围外）填充为该中性色，并在图注中说明。

## 四、标记与图表规范

| 规范 | 值 | 说明 |
|---|---|---|
| 折线宽度 | 2px | 细线，不使用粗描边 |
| 折线拐点 | 5—6px 圆点，带 1.5px 面板色描边 | 描边让重叠点可分辨 |
| 条形圆角 | 数据端 4px 圆角，基线端方角 | 圆角只在数据端 |
| 条形宽度 | 58%—62% | 留出间隙，不挤在一起 |
| 面积填充 | 自上而下 25% 透明度渐变到 0 | 提供体积感但不抢戏 |
| 网格线 | 细实线 `#1c3145`，不使用虚线满屏 | 退到背景 |
| 图例 | ≥2 个系列时必有；单系列不加图例框 | 单系列由标题命名 |
| 直接标注 | 排名条形图标注数值；散点标注省份名 | 选择性标注，不是每个点都标 |
| 数值格式 | 千分位；≥1 亿降级为「亿」、≥1 万降级为「万」 | 统一由 `MV.NF` 处理 |

## 五、明确禁止的做法（本项目已全部避免）

| 禁止项 | 本项目的做法 |
|---|---|
| **双 Y 轴** | 不同量纲的四个指标拆成 4 张小型趋势图，绝不叠在一张图上 |
| 类别型条形按数值着色 | 条形颜色只表示**区域身份**，大小由长度表达 |
| 彩虹色阶 | 地图使用单色蓝顺序色阶 |
| 用颜色单独承载信息 | 区域身份 = 颜色 + 形状 + 直接标注，三重编码 |
| 文字使用系列色 | 全部使用文字色令牌 |
| 缺测显示为 0 | 缺测显示「暂无数据」，地图填中性灰 |
| 所有图表一样大 | 地图最大，四象限次之，服务/国际在底部 |
| 满屏动画 | 仅入场过渡（`cubicOut`，620ms），无循环动画、无发光 |

## 六、Dashboards 的响应式实现

首页采用**固定舞台 + 等比缩放**：

```js
const s = Math.min(innerWidth / 1920, innerHeight / 1080);
stage.style.transform = `scale(${s})`;
```

**为什么这样做**：大屏类界面的首要目标是"版面关系不失真"。
如果改用流式布局，1920 宽下的三栏结构到 1366 宽下会挤压变形，
主次关系（地图最大、四象限第二）就无法保证。

辅助分析页则为常规滚动式布局（`body.doc-page`），
因为那是"阅读 + 逐图分析"的场景，不需要固定画布。

---

## 七、可访问性

1. **不依赖颜色单独承载信息** —— 区域用颜色 + 形状 + 直接标注；
2. **对比度** —— 全部数据色在面板上 ≥ 3:1；文字对比度更高；
3. **缺测有独立且中性的视觉表示**；
4. **全部图表在「数据说明」页可查对应数据表**（原始数据表可直接翻阅核对）；
5. **颜色不是唯一的"暂无数据"提示** —— tooltip 与表格中均显示文字"暂无数据"。
